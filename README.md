# FRIX — Potato Gang Loyalty (Demo)

Mobile loyalty prototype for **FRIX** (Amsterdams Finest / Potato Gang) in Kosovo.

## Languages

Albanian (SQ) + English (EN) — toggle in the header.

## Loyalty strategy

- **Points** on every purchase
- **Stamp card:** 3 buys = 1 free drink
- **Couples Box** reward for pairs
- **Frix Burger Menu** offer (€6 → €4)

## Pages

- `index.html` — Home, stamps, QR, deals
- `scan.html` — Till scan demo
- `rewards.html` — Redeem catalog
- `account.html` — Profile + language
